# CHILO ENGLISH — Tu historia comienza aquí

Plataforma educativa interactiva para el aprendizaje del idioma inglés con tres niveles completos (**Principiante A1-A2**, **Intermedio B1-B2** y **Avanzado C1-C2**), mascota interactiva **Chilo**, **Jardín Virtual 3D**, **Centro de Audios (27 categorías, US/UK)**, **12 categorías de juegos educativos**, **foros moderados**, **sistema de progreso y logros** y **arquitectura completa de base de datos PostgreSQL y seguridad**.

## Currículo Oficial
- **Nivel Principiante (A1-A2):** 20 temas × 9 unidades = **180 unidades** (`0/180`).
- **Nivel Intermedio (B1-B2):** 20 temas × 3 unidades = **60 unidades** (`0/60`).
- **Nivel Avanzado (C1-C2):** 20 temas × 3 unidades = **60 unidades** (`0/60`).
- **Total:** **60 temas**, **300 unidades**, **600 elementos de vocabulario** y **20 ejercicios por unidad**.

## Ejecución y Pruebas
```bash
node start.js
node 10_TESTS/verify_platform.js
```
